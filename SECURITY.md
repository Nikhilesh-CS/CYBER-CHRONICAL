# Security policy

Please report vulnerabilities through [GitHub private vulnerability reporting](https://github.com/Nikhilesh-CS/CYBER-CHRONICAL/security/advisories/new). If the private form is unavailable, contact the maintainer through a profile listed in the app. Avoid putting sensitive details in a public issue.

Include the affected route or component, the expected behavior, and the observed security impact. Redact credentials, personal data, and unrelated third-party records. Ordinary bugs and source suggestions belong in the [issue templates](https://github.com/Nikhilesh-CS/CYBER-CHRONICAL/issues/new/choose).
