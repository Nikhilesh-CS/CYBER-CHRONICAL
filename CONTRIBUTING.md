# Contributing

Use Node.js 22.13 or newer and install dependencies with `npm ci`. Run `npm run lint`, `npm test`, and `npm run check:links` before submitting a pull request.

When changing an adapter, add a small fixture that tests the publisher's structure and a changed-format case. Explain what permits collection or quotation and identify the evidence for any rating or action. Read the [source policy](docs/SOURCE_POLICY.md).

Use the [issue templates](https://github.com/Nikhilesh-CS/CYBER-CHRONICAL/issues/new/choose) for bugs or new publishers. Use the [security policy](SECURITY.md) for security reports.
